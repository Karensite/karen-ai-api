# Case: مدل زبانی آموزشیِ کوچک

این مخزن شامل یک مدل واژه‌ای n-gram است که از ابتدا و فقط با چند گفت‌وگوی نمونهٔ دست‌نویس داخل `data/sample_dialogues.json` ساخته و آموزش داده می‌شود. هیچ وزن ازپیش‌آموزش‌دیده، مدل آماده، کلید API یا سرویس هوش مصنوعی خارجی استفاده نمی‌شود. برنامه هنگام اجرا یا دریافت پیام چیزی دانلود نمی‌کند.

این مدل **دستیار قوی یا دارای درک معنایی نیست**. فقط فراوانی و ترتیب محلی واژه‌ها در نمونه‌های کوچک را می‌آموزد؛ پاسخ‌ها ممکن است تکراری، نامربوط یا نادرست باشند. این نمونه برای آموزش مفاهیم پایه است، نه استفادهٔ واقعی یا تصمیم‌گیری مهم. فایل گفت‌وگوها دادهٔ آموزشی کوچک و نوشته‌شده برای همین نمونه است؛ پایگاه دانش جداگانه‌ای در این پروژه وجود ندارد.

## اجرا و آموزش نخستین مدل

با Python 3.10 یا جدیدتر:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python train.py
uvicorn main:app --host 127.0.0.1 --port 8000
```

خروجی آموزش در `artifacts/model.json` ساخته می‌شود و در Git ثبت نشده است. پس از آموزش، `POST /api/chat` درخواست JSON مانند `{"message":"سلام"}` می‌پذیرد و `{"response":"..."}` می‌دهد. پیام باید بین ۱ تا ۲۰۰۰ نویسه باشد. `GET /health` وضعیت بارگذاری مدل را گزارش می‌کند. اگر فایل مدل موجود نباشد، API با خطای 503 و پیام عمومی می‌گوید ابتدا آموزش را اجرا کنید؛ درخواست کاربر هیچ مدلی دانلود نمی‌کند.

آموزش و تولید قطعی هستند: ترتیب یکسان داده، مدل یکسان و پاسخ یکسان می‌دهد. تست‌ها با `pytest` اجرا می‌شوند و برای مدل/API هیچ شبکه یا سرویس خارجی لازم ندارند.

## CORS و تنظیمات

برای محدودکردن CORS، متغیر محیطی `ALLOWED_ORIGINS` را با originهای دقیق و جداشده با کاما تنظیم کنید؛ اگر خالی باشد هیچ origin مرورگری مجاز نیست. نمونهٔ محلی (origin باید با میزبان/درگاه صفحهٔ وب شما تطبیق داشته باشد):

```bash
ALLOWED_ORIGINS=http://localhost:5500 uvicorn main:app --host 127.0.0.1 --port 8000
```

در Windows PowerShell قبل از اجرای uvicorn از `$env:ALLOWED_ORIGINS="http://localhost:5500"` استفاده کنید. در محیط deploy فقط origin واقعی فرانت‌اند خودتان را قرار دهید.

## تست

```bash
pytest -q
```

## استقرار آنلاین

GitHub مخزن کد است و به‌تنهایی این سرور را آنلاین اجرا نمی‌کند. برای استفادهٔ آنلاین باید این API را روی یک سرور/سرویس جداگانه deploy کنید، متغیر `ALLOWED_ORIGINS` و نشانی HTTPS را تنظیم کنید و صفحهٔ فرانت‌اند را جداگانه میزبانی کنید. نشانی زنده‌ای در کد پیش‌فرض نشده است. برای دسترسی از اینترنت، HTTPS، محدودسازی نرخ، پایش و مدیریت امن زیرساخت را نیز تنظیم کنید.
